# Ingredient Alternatives — offline kitchen reference

41 ingredients and 82 substitutions, packaged with the app for use without internet, API credentials, or GPS. To make practical replacements, the lookup displays:
- original ingredient and reference amount;
- each alternative and the amount suggested for that reference;
- best uses and differences in flavor, richness, texture, or performance;
- cautions, especially for leavening, food safety, or allergies.

The search accepts common synonyms and phrases containing a quantity such as `2 cups heavy cream`; it selects the longest whole-word ingredient match and **does not automatically scale** amounts to a user-entered quantity. Unknown inputs produce an honest no-match response.

## Where to find it

Kitchen Home → Ingredient Alternatives (both editions). Find Ingredient → Out of stock? Find an alternative. Recipe details → swap icon beside any ingredient. The guide can return you to nearby shopping.

The catalogue combines educational guidance with common culinary replacement suggestions. None is a universal guarantee. Use substitute amounts only in the stated recipe context. Check packaging for allergens, and never adapt a tested home-canning or other preservation recipe, infant formula, or medically prescribed diet based on these general ideas.
